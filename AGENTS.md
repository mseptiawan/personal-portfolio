## Next.js Development Rules

- Before writing or modifying code, check the installed Next.js version in `package.json`.
- Read the relevant documentation in `node_modules/next/dist/docs/` before using Next.js APIs or conventions.
- Follow the documentation for the installed version. Do not assume APIs, conventions, or file structures from other versions apply.
- Check for deprecation notices and breaking changes relevant to the task.
- Prefer existing project patterns and dependencies unless there is a clear reason to change them.
- Keep changes focused on the requested task. Do not rewrite unrelated files or introduce unnecessary dependencies.
- If the local documentation is unavailable or incomplete, state this limitation and verify the relevant behavior before proceeding.
